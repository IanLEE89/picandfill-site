픽앤필 홈페이지 — GitHub Pages 업로드

이 압축 파일에는 GitHub 저장소의 docs/ 폴더에 게시할 파일이 들어 있습니다.

1. 압축을 풉니다. 안의 docs/ 폴더를 GitHub 저장소에 올립니다.
   기존 docs/가 있으면 새 index.html과 assets/를 덮어써 주세요.
2. GitHub 저장소에서 Settings → Pages를 엽니다.
3. Build and deployment의 Source를 Deploy from a branch로 설정합니다.
4. Branch를 게시할 브랜치로, 폴더를 /docs로 선택하고 Save를 누릅니다.
5. 게시가 끝나면 Pages 주소에서 확인합니다.

이 사이트는 정적 파일이라 빌드 명령이나 패키지 설치가 필요하지 않습니다.
PDF 파일은 아직 제공되지 않아 PDF 다운로드 버튼은 준비 중 상태로 유지됩니다.
